十八级台阶

把 OSC 的三张公开表复算一遍之后，真正的问题不是「谁第一」，而是「表与它自己的说明书对不上」

审计对象：Open Superconductor Challenge（FINAL-Bench，托管于 Hugging Face）
数据版本：4585236f24ff｜1,073 个在役材料 · 4,832 个候选 · 1,073 条已验证记录
复现：py -3 scripts/build.py && py -3 verify/verify.py（纯标准库，无网络）

赛事的计分只有一行：index = N(E_F) × A_d(δ) × 300，其中 A_d 取自公开的 15 点表。我们把 1,073 条官方分数逐条复算：1,064 条能完全从表里算出来（最大差 5e-4，是三位小数的舍入）， 另外 9 条落在表里根本没有条目的填充上。复算本身没有问题；问题出在复算所依赖的那张表—— 它在「半满」这一格上，和赛事 README 写的物理正好相反。

1,064/1,073条分数可由公开表直接算出；9 条落在表的空洞里
12个不同的 A_d 正取值（表里共 15 个条目）
0.97平台内「分数 vs N(E_F)」的 Spearman
4/20换成 4×4 ED 的形状后，Top-20 的存活数

一、复算：1,064 条对得上，9 条落在表的空洞里

规则是 index = max(0, N(E_F) × A_d(δ) × 300)，A_d 按 Ne = 36 − round(36δ) 查 scoring_meta.json。对 submissions.csv 的 1,073 条 verified_score 逐条比对：最大绝对差 0.0005，超过 0.001 的 0 条。这印证了 README 的说法—— 每一分都是可复现的。但复算过程里冒出来两处它没写的东西：

  • 表有洞。A_d 表只有 15 个 Ne 条目，缺 Ne = 4、6、8。恰好有 9 个材料 （δ = 0.889 / 0.833 / 0.778）落在这三档，dump 里把它们写成 A_d = 0、分数 0。 「可复现」对这 9 行是靠「缺失即 0」这个未成文约定成立的，不是从表里算出来的。
  • 负值被夹零。有 88 行的表值是负数（例如 −0.00279），dump 里 85 行写成 0.0、 3 行保留负值；分数按 max(0, ·) 计。这不是错误，是规则，但它意味着「A_d = 0」有两种含义： 真的算出来是 0，和表里没有这一格。

二、半满处：表说 0.0384，README 说「消失」

这是整份审计里最硬的一条。赛事 README 在解释 A_d(δ) 的形状时写：

「A_d depends strongly on doping … vanishing at half-filling and heavy overdoping」

半满就是 δ = 0（Ne = 36，每个格点一个电子）。表里这一格给的是 0.03844，是峰值 0.05849 的 66%。而全库有 120 个材料（11%）正好落在这一格上， 它们因此拿到接近满分的 A_d。

这不是「池子里恰好有很多半满材料」的问题。在一个 U/t = 8 的 Mott 绝缘体上， d 波变分态在半满处保住三分之二的峰值关联，这本身就是「A_d 是 ansatz 人造物」的最强证据； 而赛事文档恰恰用「半满处消失」来为这个指标背书。两者只能有一个对。无论哪个对，用它来排序都需要先解释这一格。

三、于是分数 ≈ N(E_F) × 一个近似二值的填充滤波器

表里只有 12 个不同的正取值，δ 只有 18 档（偶数 Ne / 36）。 把 log 分数拆开：A_d 贡献 57% 的方差，N(E_F) 贡献 25%，协方差 18% ——「落在哪一级台阶」比「材料多能配对」更能决定分数。若只看平台内的 703 个材料， A_d 只差 1.52 倍，N(E_F) 解释了 97% 的方差，Spearman 0.968。

四、第一名坐在峰上

Top-20 全部落在 δ ≤ 0.2778 的 6 级台阶上；20 个里有 19 个的 N(E_F) 排名本来就在前 20。 榜首之争是填充位次的直接结果：

I2Mn2S 的 δ = 0.2778，正好是 A_d 的 argmax（0.05849）。Br2Fe2 的 N(E_F) 高 12%，但 δ = 0.0556 处的 A_d 低 23%，于是总分少 14%。所以「谁第一」取决于谁的填充 恰好落在峰上——这不算错，但它说明这块榜在排的是填充位次，不是材料。

五、ED 对比：能说明「次序未被识别」，不能裁决谁对

赛事公开了两份 ED 校验表。把 4×4 的 U=8 值与公布的 A_d 放在同样 5 个填充上并排：Spearman -0.60。但这个数字必须打折看：

  • 只有 5 个点。精确置换检验双侧 p = 0.35。5 个点裁决不了一条曲线。
  • 对插值方向敏感。把 ED 反向插到 15 个格点上算，ρ = -0.72；赛事自己在 validation/ 里用另一种插值读出 ≈ −0.1。三个数说明这个统计量对取点极敏感。
  • 两个团簇不是同一个量。4×4 的最大距离是 2√2，6×6 是 3√2；绝对值不可比，只能比次序。
  • ED 的「峰」也不是相互作用。n=0.5 处 U=8/U=0 = 1.03：ED 那个 0.048 里 97% 是无相互作用 的壳层值。真正被相互作用增强的是 n=0.875（1.85×），而它的绝对振幅只有 0.019。

所以这一节的结论只能写到：公布曲线随填充的次序，没有被无偏方法确认。要裁决需要更大的团簇、 更多的填充点，或者赛事公开自己的 6×6 求解器。

那把 ED 的形状代进去会怎样

把 A_d(δ) 换成 ED 的形状（归一到同一中位数，只借形状，δ > 0.5 处 ED 没有数据、记 0）， 重算 Top-20：20 个里剩 4 个（把 ED 直接插到 18 个填充档上是 2 个）。 这个数字只该读作「如果次序跟 ED 走，榜会长得完全不一样」，不能读作「ED 才是对的」。

六、稳健性：结论取决于误差结构，而公开数据定不了误差结构

赛事公开的五个团簇在同一填充上彼此相差最多 19.7 倍，n=0.5 处还变号。 用这个散布的一半（σ = 0.88）给每级台阶加扰动，但误差沿填充轴怎么相关，会决定全部答案：

  • 单个全局乘子（等价于换团簇的整体标定）：20.0 / 20，第一名 100% 不变。
  • AR(1) ρ=0.9（同一个 ansatz、同一段代码，误差应是填充的光滑函数）：15.0 / 20。
  • 逐级独立（最能打散排序的假设）：9.0 / 20，第一名保住第一的概率 27%。
  • σ 扫描（独立假设）：σ=0.4 → 14.3，0.6 → 11.7，0.88 → 9.1，1.2 → 7.3。

真实误差几乎不可能是逐级独立的：同一份代码、同一个团簇、同一套 ansatz，偏差必然随填充平滑变化。 所以「第一名只有 27% 概率保住」这句话不成立——它是 i.i.d. 假设的产物。可辩护的说法是： 排序对整体标定免疫，对随填充变化的系统误差敏感，而公开数据无法区分这两者。

七、Discovery 赛道：筛选器连已知的冠军都找不回

赛事鼓励提名新材料。我们用最朴素的化学近邻（组成向量，k=15，留一法）检验「公开描述符能不能排 N(E_F)」：

  • log N(E_F) 的 R² = 0.118，MAE = 0.450；δ 的精确命中 17%，只比众数的 14% 高一点。

更关键的是一次 sanity check——它能不能把已知的前三名排出来：

三个都低了 3.7–8.6 倍，而 759 个未降维金属里模型给出的最高预测是 1.57。 一个连冠军都压到 0.94 的模型，说「池子里最高只有 1.57」没有任何信息量——这是回归向均值收缩的算术， 不是池子的性质。诚实的结论是：公开描述符不足以做 Discovery 筛选，而不是「池子里没有挑战者」。

八、口径：这是 anchor 表，不是参赛排行榜

submissions.csv 的 1,073 行全部 is_anchor = true、作者全是 OSC-66、方法名是「canonical scoring at material's DFT filling」。这是主办方对每个材料的 标准锚点，参赛者的实时榜单不在这个 dump 里。另外 README 说榜首「currently ≈ 22」， 而这份 dump 的锚点顶到 64.02（I2Mn2S）——差三倍。两种可能：README 的数字过期了， 或者 dump 比 README 新。无论哪种，引用这块榜时都要说清是哪个口径。

九、建议

  1. 先解释半满那一格。δ = 0 给 0.0384 与 README 的「vanishing at half-filling」直接冲突， 而 120 个材料（11%）就坐在那里。这一格是整张表里最该被复核的数。
  2. 补上 Ne = 4、6、8 的表项，或明确写「未计算」。现在 dump 用 0 代替，读者分不清「没有 d 波序」 和「没算」。
  3. 分数拆两栏：台阶档位 + N(E_F)。单栏分数让人以为在看「材料多能配对」，实际在看填充位次。
  4. 把 A_d 的方法不确定带画进榜单，并且说清误差沿填充的相关性——它比误差大小更能改变排序结论。
  5. Discovery 需要一个可筛选的代理量。哪怕只对金属做一次非自洽 DOS；否则提名等于猜，DFT 排队会成为瓶颈。

十、局限

  • 不能重跑主办方的 6×6 求解器（未公开）。本报告只做公开数据的复算与公开 ED 表的再分析。
  • 4×4 ED 的最大距离与 6×6 不同，绝对值不可比；ED 本身未做尺寸收敛（贡献者 Ku-ku 自己写明）， 本报告只用它讨论次序。
  • 5 点相关（p = 0.35）不足以裁决；σ 是跨团簇散布的一半，是代理，不是置信区间。
  • 化学近邻只用组成，未用结构、层群等其余描述符；它的失败是这套模型的失败，不排除更好的模型。
  • 0.0005 的最大差是三位小数舍入，不是模型误差。
