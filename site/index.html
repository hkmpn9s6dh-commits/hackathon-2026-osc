十八级台阶

把 OSC 的三张公开表复算一遍。1,064 条分数对得上，9 条落在表的空洞里； 而表在半满那一格的值，和它自己的 README 正好相反。

1,064 / 1,073条分数可由公开表直接算出（最大差 0.0005）
12 个不同的 A_d 正取值；15 个条目里有 3 个是负的
0.0384半满（δ=0）处的 A_d，是峰值的 66%
4 / 20换成 4×4 ED 的形状后，Top-20 的存活数

一、分数是算得出来的，但表有洞

index = max(0, N(E_F) × A_d(δ) × 300)。1,073 条 verified_score 里，1,064 条能从表里算出来； 另外 9 条落在 Ne = 4/6/8 三档——表里没有这三格，dump 直接写 0。「可复现」对这 9 行靠的是约定，不是计算。

二、半满：表说 0.0384，README 说「消失」

README 写 A_d「vanishing at half-filling」。半满就是 δ = 0；表里给 0.03844，峰值的 66%。 全库 120 个材料（11%）正好坐在这一格，因此拿到接近满分的 A_d。在一个 U/t = 8 的 Mott 绝缘体上， 这本身就是「A_d 是 ansatz 人造物」的证据——而文档恰恰用它来为指标背书。

三、分数 ≈ N(E_F) × 填充滤波器

δ ≤ 1/3 的 7 级只差 1.52 倍；越过 1/3 掉 3.4 倍。平台内 log 分数与 log N(E_F) 的 Spearman 是 0.968 ——台阶之内，榜单就是 N(E_F) 榜单。

四、第一名坐在峰上

I2Mn2S 的 δ=0.2778，正好是 A_d 的 argmax；Br2Fe2 的 N(E_F) 高 12%，但 A_d 低 23%，总分少 14%。

五、ED 只能说明「次序未被识别」

5 个点上 Spearman -0.60，置换检验 p = 0.35；换一种插值读到 -0.72，赛事自己读到 ≈ −0.1。 5 个点裁决不了。但把 ED 的形状代进去，Top-20 只剩 4 个——榜会完全换一批人。

六、稳健性取决于误差结构

同样的边际 σ：整体缩放 20.0/20，平滑相关 15.0/20，逐级独立 9.0/20。 同一个 ansatz、同一段代码的误差不可能是逐级独立的——所以「第一名只有 28% 概率」这句话不成立。

七、筛选器连冠军都找不回

化学近邻的留一法 R² = 0.12；对已知前三的预测是 0.94 / 0.47 / 0.84，而真值是 3.65 / 4.08 / 3.49。 它没有能力判断池子里有没有挑战者。

八、这是 anchor 表，不是排行榜

1,073 行全部 is_anchor、作者全是 OSC-66——这是主办方的标准锚点。README 说榜首 ≈22，这份 dump 顶到 64.02。引用时必须说清口径。

九、五条建议

  1. 先解释半满那一格：0.0384 与「vanishing at half-filling」直接冲突。
  2. 补 Ne = 4/6/8，或写明「未计算」——别用 0 代替。
  3. 分数拆两栏：台阶档位 + N(E_F)。
  4. 把方法不确定带画进榜单，并说清误差沿填充的相关性。
  5. Discovery 需要一个可筛选的代理量，否则提名等于猜。
