十八级台阶

我们把 OSC 公开的三张表拿来做了一件很朴素的事：把 1,073 条官方分数逐条复算。 全部对上。于是问题变成了——这块榜到底在排什么？

1,073 / 1,073条已验证分数，逐条复现，全部对上（最大差 0.0005）
18带填充档位；A_d 只有 15 个取值
0.97平台内「分数 vs N(E_F)」的 Spearman
1 / 20换成 ED 形状后，Top-20 的存活数

一、分数是可以算出来的

index = max(0, N(E_F) × A_d(δ) × 300)。A_d 取自公开的 15 点表，δ = 1 − Ne/36。 对 1,073 条 verified_score 逐条比对，最大绝对差 0.0005（官方保留三位小数），超差 0 条。 排行榜里没有未公开的计算。

二、A_d 不是穹顶，是平台加悬崖

δ ≤ 1/3 的 7 级台阶只差 1.52 倍；越过 1/3，一次掉 3.39 倍。 平台里 log 分数与 log N(E_F) 的相关性是 0.968——台阶之内，榜单就是 N(E_F) 榜单。

三、第一名是填充的产物

I2Mn2S 拿第一，但它的 N(E_F) 只排第 2；Br2Fe2 的 N(E_F) 高 12%， 却因为填充落在平台偏低端，总分少 14%。Top-20 全部落在 δ ≤ 0.2778 的几级台阶上。

四、无偏方法不支持这条曲线的形状

用赛事自己公开的 4×4 ED（无偏参考）在同一批填充上对比，Spearman ρ = -0.60。 δ=0.5 时公布值是节点，ED 却接近它自己的最大值。把 A_d 换成 ED 的形状重算，Top-20 只剩 1 个； 按公开的跨团簇散布做扰动，Top-20 平均只剩 9.1 个，现任第一名保住第一的概率 28%。

五、Discovery 赛道卡在描述符上

只用组成做化学近邻，log N(E_F) 的留一法 R² 只有 0.12；759 个未降维金属里最高预测 N(E_F) 是 1.57， 现役前三在 3.5–4.1。公开描述符不足以筛出挑战榜首的材料——Discovery 实际依赖主办方的 DFT 算力。

六、四条建议

  1. 分数拆成两栏：台阶档位 + N(E_F)。
  2. 榜单加一列 N(E_F) 排名——平台内它才是材料间的真实序。
  3. 把 A_d 的方法不确定带画进榜单，而不是只写在 README 的 caveat 里。
  4. Discovery 需要一个可筛选的代理量（哪怕粗算 DOS），否则提名等于猜。
